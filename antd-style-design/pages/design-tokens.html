设计令牌 · Design Tokens & Typography

本页面是设计 ↔ 开发的 token 字典：色板 / 字号 / 间距 / 圆角 / 阴影 / 动效。所有 token 通过 var(--antd-*) 暴露，对应 antd v5 <ConfigProvider theme={{token: {...}}}> 中的 theme.token 字段，迁移零成本。

02 · Typography

字号矩阵

xs(12) / sm(13) / base(14) / lg(16) / xl(18) / 2xl(20) / 3xl(24) / 4xl(30) / 5xl(38)。对应 antd theme.token.fontSize。所有字号都是行高 1.5715 下的实际值，避免使用 4xl / 5xl 整段文本。

--antd-font-size-xs 12px 辅助说明 / 标签内字 用于 tag / pill / 表格副文本
--antd-font-size-sm 13px 次级正文 / 表头说明 用于表头、描述、kpi-label
--antd-font-size / base 14px 主体正文 / 表格行 默认正文，业务页 80% 场景
--antd-font-size-lg 16px 加强正文 / 卡片标题 card-title / 强调字段
--antd-font-size-xl 18px 弹窗标题 / 区块标题 Modal 标题、Section h3
--antd-font-size-2xl 20px 页面标题 / 业务页 h1 page-head-title
--antd-font-size-3xl 24px 大数字 / 重要数字 专题大数字、统计大数
--antd-font-size-4xl 30px 核心 KPI 数字 antd-kpi-value / 强调 stat
--antd-font-size-5xl 38px 超大数字 / 营销展示 专题封面、报告头图

05 · Motion

动效矩阵

关键帧 3 个：pulse（状态点呼吸）、skel（骨架闪烁）、fade-in（淡入 0.2s）。transition 0.2s 缓动（cubic-bezier 0.645, 0.045, 0.355, 1）覆盖 hover 缩放、按钮 active 反馈、tab 切换 underline。3 个 hover 按钮分别演示 0.2s 缓动。

关键帧 · Keyframes · 3 个

pulse
@keyframes pulse · 1.4s
skel · skeleton
@keyframes skel · 1.4s ease infinite
fade-in
@keyframes fadeIn · 0.2s

transition 0.2s 缓动 · 3 种用法

所有交互过渡统一用 cubic-bezier(0.645, 0.045, 0.355, 1)，时长 0.2s。
