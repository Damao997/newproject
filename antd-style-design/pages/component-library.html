组件库总览 · 设计↔开发对照手册

本页面是设计 / 研发 / 测试的「组件 ↔ token ↔ 代码片段」三方对照。每个分区给出：组件名 → 视觉演示 → HTML 片段 → 适用场景。所有色值与尺寸均通过 --antd-* 变量驱动，对应 antd v5 ConfigProvider theme.token，禁止写死 hex / px。

07 · Don't

已废弃 / 不要使用 · 红榜

以下 4 类用法在设计库迭代中已废弃。设计交付时如果出现，请打回。

① 自定义色按钮 已废弃

业务方曾要求把「重点客户」按钮染成紫色 / 绿色——紫色不在主色板，绿色是 success 状态色，混用造成语义混乱。统一改用 .antd-btn-primary + antd-emphasis-warm-strong 承载重点。

/* 反例 · 禁止 */
.antd-btn-blue { background: #722ed1; }
.antd-btn-purple { background: #13c2c2; }
/* 正例 */
<button class="antd-btn-primary">重点客户</button>

② 老版 kpi-card 已废弃

老项目用 .kpi-card + .kpi-success/.kpi-warning/.kpi-error/.kpi-info 4 个修饰符。色条硬编码无 token 体系。新版用 .antd-stat-tile + 4 色 is-*，左侧 3px 色条 + spark + chip。

/* 反例 */
.kpi-card.kpi-warning { ... }
/* 正例 */
<div class="antd-stat-tile is-cyan">...</div>

③ 未经强调的弱 KPI 标数 已废弃

老设计里 KPI 数字直接用 antd-kpi-value 28px 但无 spark / chip / 趋势 — 与表格数字无法区分。强 KPI 必须用 .antd-stat-tile；表格内数字继续用 .antd-kpi-value。

/* 反例 */
<div class="antd-kpi-value">1,284.6</div>
<!-- 无 spark / 无 chip / 无 is-orange 修饰 -->
/* 正例 */
<div class="antd-stat-tile is-orange">...</div>

④ 直接写死 rgba / hex 已废弃

任何颜色 / 字号 / 间距必须走 token。直接写 #1677ff 或 rgba(22,119,255,.1) 会让主题切换失效。统一替换为 var(--color-primary) / var(--antd-brand-50) 等。

/* 反例 */
.card { background: #f0f7ff; }
.dot  { box-shadow: 0 0 0 4px rgba(250,140,22,.12); }
/* 正例 */
.card { background: var(--antd-brand-50); }
.dot  { box-shadow: 0 0 0 4px var(--antd-orange-bg); }
