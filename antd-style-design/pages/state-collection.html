§4 何时用哪个态 · 决策表

触发场景 使用态 关键文案 主操作 副操作
模块首次进入，无任何配置EMPTY还没有数据 / 该模块尚未配置立即配置查看文档
首屏加载中LOADING正在加载…—取消
局部表格刷新SKELETON（无文字，仅骨架）——
接口 500 / 渲染异常ERROR加载失败 + 错误码重新加载查看日志 / 反馈
角色无权访问整页403无权访问 + 角色名 + 缺失权限申请权限返回首页
字段级越权MASK（脱敏显示）申请权限—
筛选无结果（无错误）NO DATA所选条件下暂无数据 + 条件摘要清除筛选扩大范围
断网 / 接口超时OFFLINE网络连接已断开 + 草稿保留提示重新连接查看草稿
服务降级（部分功能不可用）BANNER服务降级中 + 影响范围—了解详情

  .illust-empty / .illust-loading / .illust-error
  .illust-noperm / .illust-nodata / .illust-offline
.antd-state-title         /* 标题：14px 600 */
.antd-state-desc          /* 描述：12px #8c8c8c */
.antd-state-action        /* 操作区 */
.antd-state-btn           /* primary */
.antd-state-btn.is-ghost  /* ghost */
.antd-state-btn.is-default/* 默认次按钮 */

.antd-state-card-head     /* 卡片头（带编号 + 标签） */

.mask-cell                /* 字段脱敏 */
