## 三、已实施的变更（本次修复）

### 3.1 比率类指标统一百分比格式（1 位小数）

- `web/src/lib/utils.ts` `formatPercent`：`toFixed(2)` → `toFixed(1)`（0.235 → 23.5%）。影响达成率、分析抽屉同比等全部调用点。
- 同比 / 累计同比 / 变动率 / KPI 同比徽标此前已是 1 位小数，保持不变。
- 单元测试 `web/src/lib/__tests__/utils.test.ts` 同步更新。
- **实测**：财务指标页 54 个百分比值均为 `X.X%` 格式。

### 3.2 数字统一微软雅黑字体

- `web/tailwind.config.js` 新增 `font-num` 字体族：`"Microsoft YaHei" / "微软雅黑"` + `fontFeatureSettings: "tnum"`（等宽数字特性，保证表格数字纵向对齐，弥补微软雅黑非等宽的问题）。
- 数字展示场景由 `font-mono` 全部替换为 `font-num`：
  - 指标树数值单元格与涨跌百分比（`metric-tree.tsx`）
  - KPI 卡片大数值与同比徽标（`kpi-card.tsx`）
  - 分析抽屉指标上下文（`analysis-drawer.tsx`）
  - 数据管理页交叉表 / 行号 / 入库明细 / 成功异常 / 金额合计 / 样例数据表（`data/index.tsx`）
  - 重分类三组件金额展示（`reclassify-*.tsx`、`shared.tsx`）
  - 轻量柱状图数值、公式试算结果（`mini-bar-chart.tsx`、`formula-maintenance.tsx`）
- ECharts：趋势图新增全局 `textStyle.fontFamily: Microsoft YaHei`，tooltip 内联字体同步替换。
- **保留 `font-mono`（等宽代码字体）的场景**：公式文本 / 公式编辑框、科目编码、公司编码、确认对话框输入令牌 —— 这些属代码 / 标识符而非数字展示。
- **实测**：`getComputedStyle(.font-num).fontFamily` 返回 `"Microsoft YaHei", 微软雅黑, sans-serif`。
- **说明**：此变更取代原"数值列必须等宽字体（JetBrains Mono）"规范，对齐能力由 `tnum` 特性承接。

### 3.3 首页与数据预览去"万"字

- 首页看板：KPI 卡片大数值 `formatMoney` → `formatMoneyWan`；趋势图 tooltip `xx.xx 万` → 千分位纯数字。
- 数据管理页：交叉表数值、导入预览"金额合计"改为纯数字，"金额合计"标签补充"(万)"单位说明避免语义丢失。
- **明确不受影响**（保持带单位显示）：指标页分析抽屉"预算(万)"等标签、重分类对话框金额（formatMoney）、往来分析页金额缩写、各页 Excel 导出列头"(万)"。
- **实测**：首页 KPI、趋势图 tooltip、交叉表均已无"万"字。

## 五、补充：科目值类型（valueType）分型展示改造（同日追加）

针对“金额/数量/比率三类指标被统一按金额渲染”的问题（比率显示 0.24 而非 23.5%、数量带两位小数），已落地完整 valueType 方案：

- 后端：`AccountSubject` 新增 `valueType` 枚举（amount/quantity/ratio，默认 amount，migration `20260727153046_add_subject_value_type`）；seed 按名称规则自动打标（含“率/占比”→比率，含“户数/天数”→数量，劳效比显式覆盖），回填结果 152 金额 / 31 比率 / 4 数量；经营/静态指标、交叉表、科目树、科目 CRUD 均透出该字段。
- 比率同比语义修正：比率科目的同比/累计同比/变动率改为百分点差（pp），前后端一致，避免 20%→22% 被显示成 +10% 的误导。
- 前端：新增 `formatMetricValue/formatQuantity`（lib/utils.ts）统一分发；指标树、交叉表、分析抽屉（仅金额标“(万)”）、Excel 导出均按类型渲染。
- 验证：后端 typecheck + 252 测试、前端 61 测试 + 构建全部通过；浏览器实测比率百分比/pp、数量整数、金额千分位均正确，0 console 错误。
- 遗留：科目新建/编辑对话框暂未提供 valueType 选择入口（新建默认 amount，后端接口已支持，可后续补 UI）。
