# 管理口径财务数据平台 — 前端模块架构

> ⚠️ **[已废止]** 原始 PRD（4模块版本）。13条用户故事 + 4个UI布局草图已提取到 `../整体方案v3.md` §一~§二。AI Agent 请 Read `../整体方案v3.md`。

## Context
- **平台定位**：管理口径财务工具，Excel 进 → 看板/报表出
- **目标用户**：内部业务人员（运营、财务、部门经理等非技术角色）
- **技术栈**：React + TypeScript
- **设计原则**：低门槛、财务数据准确性优先、PC 端为主

---

## 模块总览

```
登录页 → 首页看板（登录后默认进入）
  ├── 财务指标
  ├── 往来分析（六大往来）
  ├── 存货管理
  ├── 分析报告（手工录入 + AI润色）
  ├── 数据管理
  └── 权限管理
```

## 二、首页看板

> 登录后的默认落地页，全局视角的核心数据一览

| 功能点 | 说明 |
|--------|------|
| **KPI 概览卡片** | 收入/成本/利润/现金流 4~6 个核心指标，对比预算/同期 |
| **趋势迷你图** | 近 12 个月收入/费用趋势 sparkline |
| **预警提醒** | 异常指标标红（超预算、回款逾期、库存积压等） |
| **快捷入口** | 跳转至常用功能：导入数据、新建报告、往来查询 |
| **数据截至时间** | 顶部醒目位置标注"数据更新时间：YYYY-MM-DD HH:mm" |

## 三、财务指标

> 核心财务 KPI 的详细展开，支持多维度下钻分析

| 功能点 | 说明 |
|--------|------|
| **指标树** | 按财务分析框架组织：盈利能力 → 毛利率/净利率/ROE；营运能力 → 周转率/周转天数；偿债能力 → 流动比率/资产负债率 |
| **期间对比** | 本月 vs 上月、本年 vs 去年同期，绝对值 + 变动率 |
| **预算对比** | 实际 vs 预算，偏差率，条件格式（红绿标识） |
| **维度切换** | 按部门/项目/区域/科目切片查看同一指标 |
| **趋势图** | 选定指标的 12 个月趋势折线图 |
| **表格明细** | 指标底层数据明细表，支持导出 Excel |

## 四、往来分析（财务六大往来）

> 六大往来：**应收账款、应付账款、预收账款、预付账款、其他应收款、其他应付款**

### 4.1 六大往来总览
- 6 张卡片，分别显示各往来科目期末余额、较期初变动、占总资产比例
- 支持按时间区间（月/季/年）切换

### 4.2 客商明细
- **双主体维度**：支持按**公司主体**（法人实体）和**管理主体**（管理口径合并范围）两个维度分别查看
- **内部抵消**：标记关联方/内部公司交易，支持"含内部"和"剔除内部"两种视角一键切换，确保管理口径数据不受内部交易虚增
- 按客商展开每个往来科目的余额明细，含期初余额、本期借方、本期贷方、期末余额
- 支持按客商名称、金额区间、账龄区间筛选

### 4.3 账龄分析
- 账龄区间（1 月内 / 1-3 月 / 3-6 月 / 6-12 月 / 1-2 年 / 2 年以上）
- 可视化：堆叠柱状图（按账龄分层）+ 饼图（账龄占比）
- 表格：客商 × 账龄矩阵表，条件格式高亮长账龄
- 坏账预估：按账龄区间 × 计提比例自动计算

### 4.4 催收计划
- **催收列表**：按逾期金额、账龄排序的待催收清单
- **催收计划录入**：逐笔设定催收负责人、计划催收日期、催收方式（电话/函证/法务）、预计回收金额
- **催收进度跟踪**：计划 vs 实际回收对比，催收状态流转（待催收→催收中→部分回收→全额回收→坏账核销）
- **催收记录**：每次催收动作的时间线记录，支持附件上传（函证扫描件等）

## 五、存货管理

> 聚焦库存金额与相关财务指标，不做进销存流水和盘点

| 功能点 | 说明 |
|--------|------|
| **库存金额总览** | 按品类/仓库/库龄展示库存账面金额，期末时点数据 |
| **库龄金额分布** | 按库龄区间（30/60/90/180/365 天 / 1 年以上）展示各区间库存金额及占比，识别呆滞 |
| **存货周转指标** | 存货周转率、周转天数、较同期/预算对比 |
| **跌价准备** | 按库龄 × 跌价计提比例估算存货跌价准备金额 |
| **趋势图** | 库存金额月度趋势、周转率变化趋势 |

## 六、分析报告

> **核心差异化模块**：手工录入报告框架 + AI 润色 + 分模块管理

| 功能点 | 说明 |
|--------|------|
| **报告模板** | 预置分模块模板：经营分析报告、财务分析报告、预算执行报告、部门经营简报 |
| **分模块录入** | 每个报告拆分为多个模块（如：收入模块、成本模块、费用模块、资金模块），每个模块独立录入 |
| **数据自动填充** | 模块中可引用的指标数据自动从系统拉取（本期收入、同比等），减少手工输入 |
| **手工文本录入** | 富文本编辑器，支持表格、图片粘贴，业务人员撰写分析文字 |
| **AI 润色** | 选中文本 → AI 一键润色（修正语法、优化表达、统一专业术语），支持： |
|  | - 润色风格可选：正式汇报/简明摘要/通俗解读 |
|  | - 支持追加 AI 分析（如"基于上述数据，补充趋势分析"） |
| **报告组装** | 各模块完成后一键组装为完整报告，自动生成目录、页码、表头 |
| **导出** | Word（保留格式）/ PDF |
| **历史版本** | 每次修改保存版本，支持版本对比和回退 |
| **协作** | 报告可分享链接给他人查看/评论（非编辑） |

## 七、数据管理

> Excel 导入 + 数据维护的入口

| 功能点 | 说明 |
|--------|------|
| **Excel 导入** | 拖拽上传、模板下载、字段映射、数据预览、校验（类型/必填/范围） |
| **导入历史** | 批次记录，成功/失败行数，支持回滚撤销 |
| **数据表浏览** | 分数据域展示（收入表、费用表、往来表、存货表等），在线筛选排序 |
| **在线编辑** | 单元格编辑、批量修改、行删除/恢复 |
| **维度维护** | 部门、项目、科目、客商等基础维度 CRUD |
| **数据快照** | 月末/季度末自动快照，用于对账和审计回溯 |

## 八、权限管理

| 功能点 | 说明 |
|--------|------|
| **用户管理** | 用户列表、启用/停用、重置密码 |
| **角色管理** | 预置角色（管理员/财务主管/部门经理/查看者），自定义角色 |

## 路由结构

```
/login                         → 登录页
/dashboard                     → 首页看板
/indicators                    → 财务指标
/indicators/:id                → 指标详情（下钻）
/transactions                  → 往来分析总览（六大往来）
/transactions/:type            → 单个往来科目明细（应收/应付/预收/预付/其他应收/其他应付）
/transactions/:type/aging      → 账龄分析
/transactions/collection       → 催收计划列表
/transactions/collection/:id   → 催收计划详情
/inventory                     → 存货管理（库存金额+财务指标）
/reports                       → 分析报告列表
/reports/:id/edit              → 报告编辑器（分模块）
/reports/:id/preview           → 报告预览
/data/import                   → 数据导入
/data/tables                   → 数据表管理
/data/dimensions               → 维度维护
/settings/users                → 用户管理
/settings/roles                → 角色管理
/settings/logs                 → 操作日志
```

## 技术选型

| 层级 | 方案 |
|------|------|
| 框架 | React 18 + TypeScript + Vite |
| UI 组件库 | Ant Design 5（企业级，表格/表单极强） |
| 图表 | ECharts (echarts-for-react) |
| 富文本 | TipTap（AI 润色集成友好）或 Quill |
| Excel 处理 | SheetJS (xlsx) 读取 + exceljs 写入 |
| 状态管理 | Zustand |
| 请求 | axios + TanStack Query (react-query) |
| 路由 | React Router v6 |
| 精度计算 | decimal.js（财务浮点数精度方案） |
| AI 集成 | 流式输出 SSE，对接后端 LLM 接口 |
