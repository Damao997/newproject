# 浙江壹品慧财 · 财年经营数据分析平台

> 文档定位：**项目概述**（Project Overview）。本文件定义平台定位、核心特性、全文档统一术语表、技术栈与文档导航。

---

## 1. 平台简介

浙江壹品慧财财年经营数据分析平台（以下简称"平台"）面向企业**财年经营分析**场景，围绕两大核心能力构建：

- **财年滚动对比**：财年定义为每年 **4 月 1 日 ~ 次年 3 月 31 日**，"去年 / 今年"随当前日期自动逐年滚动。
- **同比分析**：以"双年度对"为完整度单元，按月成对追加导入（如 `2025-04 + 2026-04`），支持同比 / 环比、累计同比与预警。

平台提供经营指标看板、财务指标明细、数据导入管理、权限管理等模块，帮助财务与经营分析人员快速掌握财年进度与同比表现。

> **当前交付状态**：项目处于规划与文档建设阶段。前端方案采用 v3 纸质感设计（Radix UI + Shadcn/ui）。文档体系采用 CLAUDE.md（AI Agent 入口）+ 四分类结构（references/ + plans/ + data-templates/ + archive/）。

## 2. 核心特性

| 特性 | 说明 |
|---|---|
| 财年滚动对比 | 财年 = 4/1~次年 3/31；去年 / 今年随当前日期自动逐年滚动 |
| 同比分析 | 以"双年度对"为完整度单元，支持同比 / 环比、累计同比、波动预警 |
| 数据导入 | 拖拽 / 点击上传 → 预览 → 校验 → 幂等导入 → 导入历史 |
| 权限管理 | 角色、功能权限矩阵、数据权限范围、审计日志 |
| 纸质感 UI | 白底 + 细边框 + 克制阴影（纯 CSS 动画，Design Token 变量化），桌面侧边栏 / 移动端响应式 |
| 红涨绿跌 | 遵循中国财务习惯（涨红 `#FF3B30` / 跌绿 `#34C759`），"好坏"另由指标 `good_when_up` 判定 |

## 3. 术语表（全文档统一）

> 本表为全文档唯一术语来源，其余各篇引用时不再重复定义。

| 术语 | 英文 / 缩写 | 定义 |
|---|---|---|
| 财年 | FY / Fiscal Year | 每年 **4 月 1 日 ~ 次年 3 月 31 日**；以起始年命名，如 `FY2025 = 2025-04-01 ~ 2026-03-31` |
| 今年 | Current FY | 截至当前日期所属、进行中的财年 |
| 去年 | Previous FY | 上一个完整财年（今年 − 1） |
| 滚动 | Rolling | 去年 / 今年随当前日期自动逐年切换 |
| 成对追加导入 | — | 每月以"基准年 X 月 + 当前年 X 月"双年度组合方式追加导入 |
| 完整度单元 | — | 一个自然月的双年度对；成对导入到位后该月同比 100% 可算 |
| 同比 | YoY | 同一自然月、不同财年的值对比（如 `2026-04` vs `2025-04`） |
| 环比 | MoM | 相邻期间对比（如 `2026-05` vs `2026-04`） |
| 红涨绿跌 | — | 数值上升为红（`#FF3B30`）/ 下降为绿（`#34C759`）；好坏语义由指标 `good_when_up` 判定 |
| 幂等 upsert | — | 按 `(company_id, indicator_code, period_year, period_month)` 主键冲突时更新，避免重复导入翻倍 |
| 批次 | Batch | 一次导入的元数据（覆盖期间、导入人、状态、行数、错误数） |
