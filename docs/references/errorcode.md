# 错误处理与错误码规范（模块 9）

## 统一响应格式

```json
{
  "code": 0,
  "data": {},
  "message": "success",
  "traceId": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
}
```

- `code` 为 **0** 表示成功，非 0 表示错误
- `message` 为人类可读描述，简体中文
- `data` 仅成功时返回业务数据
- `traceId` 每个请求生成全局唯一 ID，贯穿日志链路，由 express-request-id 中间件自动注入

## HTTP 状态码映射

| code | HTTP 状态码 | 含义 | 说明 |
|------|------------|------|------|
| 0 | 200 | 成功 | 正常业务响应 |
| 400 | 400 | 参数校验失败 | Zod 校验未通过 |
| 401 | 401 | 未登录/Token 失效 | 无 token / 已过期 / 已在黑名单 |
| 403 | 403 | 权限不足 | 角色无 resource:action 权限 / scope 不覆盖 |
| 409 | 409 | 资源冲突 | 唯一约束冲突 / 重复导入 / 版本冲突 |
| 429 | 429 | 请求频率超限 | 速率限制触发 |
| 500 | 500 | 服务端内部错误 | 未捕获异常，返回通用 message 不暴露细节 |

## 错误码分类（扩展用）

| 范围 | 类别 | 说明 |
|------|------|------|
| 10000–19999 | 参数错误 | 输入校验失败（保留扩展） |
| 20000–29999 | 业务错误 | 业务规则失败（如余额不足） |
| 30000–39999 | 认证授权 | 身份/权限不足 |
| 40000–49999 | 第三方错误 | 外部服务失败（如 DeepSeek API 超时） |
| 50000–59999 | 系统错误 | 服务器内部异常 |

## 异常处理策略

| 异常类别 | 处理策略 |
|----------|----------|
| 参数错误 | 直接返回 400，不重试 |
| 业务错误 | 直接返回对应 code，不重试 |
| 认证授权 | 返回 401/403，不重试 |
| 第三方错误 | 记录日志 + 指数退避重试（≤3 次） |
| 系统错误 | 记录日志 + 告警 + 降级响应 |
