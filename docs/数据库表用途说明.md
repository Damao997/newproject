# 数据库表用途说明

> **适用项目**：浙江壹品慧财年经营数据分析平台（`yipinhui_finance_analytics`）
> **数据来源**：`server/prisma/schema.prisma`（40 张表 + 14 个枚举）
> **更新日期**：2026-08-21

---

## 一、维度表（主数据，12 张）

| 表名 | 用途 |
|---|---|
| `company` | **公司主体表**：所有公司主体（单体会 EN / 汇总体 ET），含实体类型、法律主体、管理主体、上级公司、启用状态与排序 |
| `company_aggregation_map` | **汇总映射表**：汇总公司 ↔ 单体公司归属关系，`is_internal_elimination` 标记内部抵消关系 |
| `account_subject` | **科目体系表**：经营/静态/现金流/往来/总览五类科目树（编码、层级、借贷方向、值类型、是否叶子） |
| `product_category` | **品类配置表**：品类预算达成分析用的「品类 ↔ 收入科目名关键词」映射，科目树变动后由管理员维护 |
| `expense_subject_mapping` | **运营费用映射表**：运营费用分析中「展示指标 ↔ 经营科目编码集合」映射，软删除（墓碑）防 seed 复活 |
| `subject_budget_config` | **主体展示配置表**：主体预算达成分析中配置展示哪些公司、排序、启停 |
| `budget_ratio_config` | **预算月度占比配置表**：按财年配置 12 个月预算占比（和为 100），看板月度预算按此拆分，未配置回退默认占比 |
| `period_dimension` | **期间维度表**：期间定义（月度/季度/年度等），`is_calculated` 标记计算期间及其计算公式 |
| `transaction_account` | **往来会计科目主数据**：集团统一科目表中六大往来相关科目（12 位科目段值） |
| `counterparty` | **客商表**：客户/供应商主数据，含内部/关联/外部标记与联系方式 |
| `dimension` | **维度通用表**：预留的业务单元/区域/项目等维度定义 |
| `dimension_member` | **维度成员表**：维度下的成员（支持父子层级与排序） |

## 二、事实表（业务数据，6 张）

| 表名 | 用途 |
|---|---|
| `fact_operating` | **经营数据事实表**：月度经营数据（公司×科目×期间×期间维度，批次幂等唯一），现金流数据同存于此 |
| `fact_static` | **静态数据事实表**：时点类静态数据（按快照日期而非期间存储） |
| `fact_budget` | **年度预算事实表**：年度预算值（公司×科目×财年×期间） |
| `fact_snapshot` | **导入数据快照表**：批次激活覆盖时被删行的备份，支撑批次回滚（同批次可多次快照） |
| `reclassification_log` | **重分类记录表**：跨公司/科目归类调整的审计追溯，含行级快照支持撤销、失效标记 |
| `consolidation_adjustment` | **汇总抵消调整表**：汇总主体聚合口径上的抵消金额调整（解决内部公司间交易重复计算），软删除即撤销 |

## 三、业务表（往来/存货/催收，8 张）

| 表名 | 用途 |
|---|---|
| `transaction_detail` | **往来明细表**：六大往来（应收/其他应收/预收/应付/其他应付/预付）逐行明细，含期初期末余额、借贷方发生额、**10 段账龄**、内部往来标记与抵消状态 |
| `aging_record` | **账龄记录表**：按账龄段汇总的余额快照（6 段账龄桶） |
| `salesman` | **业务员表**：催收计划归属的业务员，按公司隔离，inactive 为停用 |
| `salesman_company` | **业务员-公司关联表**：一个业务员可归属多个公司 |
| `collection_plan` | **催收计划表**：逾期款项的催收计划（逾期金额、计划日期、方式、预期/实际收回、状态机） |
| `customer_ext` | **客商扩展表**：应收款台账补录（未建催收计划时补业务员/已开票未收款金额） |
| `collection_log` | **催收记录表**：每个催收计划的动作流水（时间、操作人、内容、附件） |
| `inventory_record` | **存货记录表**：按公司×期间×品类的账面金额 |

## 四、报告相关表（7 张）

| 表名 | 用途 |
|---|---|
| `report_template` | **报告模板表**：报告结构模板（JSON 结构定义） |
| `report` | **报告主表**：报告元信息（标题、财年、期间、公司范围、状态、当前版本） |
| `report_section` | **报告章节表**：报告下的章节，可通过 `analysis_id` 实时引用单项分析 |
| `report_version` | **报告版本表**：每次改动的完整 JSON 快照，支持版本追溯 |
| `report_comment` | **报告评论表**：报告/章节级批注评论 |
| `report_share` | **报告分享表**：分享令牌、过期时间、浏览量 |
| `subject_analysis` | **单项分析表**：分析师对「公司×科目×期间」撰写的单项分析，汇总报告实时引用最新内容 |

## 五、系统表（11 张）

| 表名 | 用途 |
|---|---|
| `user` | **用户表**：账号、密码哈希、角色、数据范围（多公司）、强制改密、多会话刷新令牌 jti 列表 |
| `role` | **角色表**：预置 5 角色 + 自定义角色，含数据范围类型 |
| `permission` | **权限表**：角色×资源×操作（7 种操作）的授权矩阵 |
| `token_blacklist` | **Token 黑名单表**：登出/失效的 jti 令牌，防重放 |
| `metric` | **指标表**：指标定义（data/calc/display 三类，计算公式、依赖指标、来源科目、版本） |
| `metric_definition_history` | **指标口径历史表**：指标公式变更留痕（含审批人） |
| `import_batch` | **导入批次表**：每次数据导入的批次（文件、状态、行数、错误、生命周期 draft→active→purged、覆盖范围申报） |
| `mapping_scheme` | **映射方案表**：导入列映射方案（用户可保存复用） |
| `audit_log` | **审计日志表**：全模块操作审计（用户、模块、动作、IP、UA），生产按月分区 |
| `ai_desensitize_config` | **AI 脱敏配置表**：AI 场景的敏感数据脱敏规则（金额/客商/科目） |
| `alert` | **预警表（预留）**：指标阈值预警，当前仅建表未启用 |

## 六、其他工具表（2 张）

| 表名 | 用途 |
|---|---|
| `enterprise_info` | **企业工商信息缓存表**：外部查询结果缓存（信用代码唯一，带过期时间） |
| `enterprise_query_log` | **企业工商查询历史表**：按用户记录查询关键词与命中情况 |

## 附：命名规范速查

- 表名：`snake_case` 单数，列名 `snake_case`，多词字段强制 `@map`
- 前缀：`fact_` 仅限三张导入事实表；`ai_` 为 AI 域配置表；其余不加前缀
- 后缀速查：`_log` = append-only 流水；`_version` = 内容快照；`_history` = 定义变更留痕；`_map` = N:N 关联；`_scheme` = 配置方案；`_record` = 周期记录；`_detail` = 行级明细
- 核心主数据（`company` / `account_subject` / `period_dimension`）与业务数据（`transaction_detail` / `fact_*`）通过 `code` 字符串关联，而非数据库外键（增量交付策略，详见 schema 头部注释）
