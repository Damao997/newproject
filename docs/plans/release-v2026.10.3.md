# v2026.10.3 财务指标表格首列冻结修复发布记录

## 一、变更内容（缺陷修复，用户可感知）

财务指标页面（经营 / 静态 / 现金流）表格横向滚动时，首列「科目」被裁切成科目名后缀、较短名称整行空白，且与表头「科目」错位。

- 根因：首列数据单元格的 `sticky` 缺少 `left` 偏移 —— `position: sticky` 的 inset 为 `auto` 时不产生吸附位移；而表头「科目」带 `left-0` 仍吸附，导致表头与数据行首列行为不一致。
- 修复：首列单元格补 `left-0`；组名行 z-index 由 `z-[2]` 提升至 `z-[3]`（「科目」th 同步 `z-[4]`），消除明细表头行白底截断「科目」表头背景的次要缺陷。
- 新增回归测试：断言表头「科目」与数据行首列均带 `sticky` + `left-0`。

本次不涉及业务逻辑、接口或数据口径变更。
