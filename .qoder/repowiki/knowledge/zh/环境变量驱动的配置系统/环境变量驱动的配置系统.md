该项目的配置系统基于 **dotenv + process.env** 实现，采用集中式加载与严格校验的模式，所有运行时配置均通过环境变量注入，无配置文件（如 .yaml/.toml）或数据库配置表。

### 核心机制
- **统一入口**：`server/src/config/env.ts` 提供 `loadConfig()` 函数，使用 `dotenv.config()` 在模块加载时自动读取 `.env` 文件，并通过 `required()` / `optional()` 两个辅助函数对每个环境变量进行取值与校验。
- **单例缓存**：`loadConfig()` 内部维护 `cached` 变量，确保配置只解析一次，避免重复 IO。
- **类型安全**：导出 TypeScript 接口 `AppConfig`，包含 `nodeEnv`、`port`、`databaseUrl`、`jwtSecret`、`jwtRefreshSecret`、`accessTokenTtl`、`refreshTokenTtl`、`frontendOrigin`、`bcryptCost`、`logLevel`、`deepseekApiKey`、`deepseekApiBase`、`deepseekModel`、`fiscalStartMonth` 等字段。
- **启动即校验**：`server/src/server.ts` 的 `bootstrap()` 在应用启动时立即调用 `loadConfig()`，任何缺失或非法的环境变量都会抛出异常并中止服务，遵循“失败即快速失败”原则。

### 关键约束与安全策略
- **必填项强制**：`DATABASE_URL`、`JWT_SECRET`（长度≥32）、`JWT_REFRESH_SECRET`（长度≥32）为必填，缺失直接抛错拒绝启动。
- **安全红线**：注释明确引用 `docs/references/security.md`，禁止对敏感密钥使用默认回退值。
- **数值校验**：`PORT` 必须为合法数字；`BCRYPT_COST` 必须 ≥12，否则抛错。
- **可选配置**：`DEEPSEEK_API_KEY` 为空字符串时返回 `null`，允许 AI 功能按需启用。
- **财年配置**：`FISCAL_START_MONTH` 由 `lib/period.ts` 的 `getFiscalStartMonth()` 单独读取，支持 1–12 范围，非法值回退为 1。

### 使用模式
- 后端各模块通过 `import { loadConfig } from './config/env'` 获取配置，如 `lib/jwt.ts`、`lib/logger.ts`、`lib/password.ts`、`middleware/cors.ts`、`lib/deepseek.ts` 等。
- 脚本类工具（如 `scripts/ai-smoke.ts`、`scripts/ai-pipeline-smoke.ts`）通过 `import 'dotenv/config'` 直接加载环境变量。
- 种子脚本 `prisma/seed.ts` 也直接读取 `process.env.SEED_DEFAULT_PASSWORD` 和 `BCRYPT_COST`。

### 约定与环境文件
- 开发环境配置集中在 `server/.env`，包含本地 PostgreSQL 连接串、JWT 密钥、CORS 源、日志级别等。
- 部署时应通过容器环境变量或平台配置中心注入对应键值，不提交敏感信息到版本库。
