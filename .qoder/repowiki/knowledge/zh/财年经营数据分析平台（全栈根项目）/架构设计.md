根目录作为编排层，通过 CLAUDE.md 向 AI Agent 暴露统一的开发规范与技术栈约束，实际代码按职责拆分为三子模块：web 通过 REST API 调用 server，server 经 Prisma 访问 PostgreSQL；docs 存放 schema、API 设计、安全与部署等权威参考，被前后端共同引用。中间件链在 server 启动时串联 helmet→cors→express.json→速率限制→auth(JWT)→permission(默认拒绝)→scope(软删除过滤)→audit→Service→Prisma，形成跨所有路由的统一横切能力。权限模型以 Resource 三段式编码 '模块:子页面:操作' 贯穿 admin、data、indicators、dashboard、reports、ai 等路由，由 permission 中间件统一校验。
