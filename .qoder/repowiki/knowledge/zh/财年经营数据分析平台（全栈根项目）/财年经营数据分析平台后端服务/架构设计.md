模块采用经典的三层结构：`src/server.ts` 为启动入口，调用 `loadConfig()` 校验环境变量后通过 `createApp()` 组装 Express 应用；`src/app.ts` 集中装配中间件链（traceId → helmet → cors → json → 通用限流 → 路由 → 404 → 全局错误处理），并按 `/api/v1/{auth,dashboard,indicators,data,admin,ai,reports,transactions,tools}` 挂载 9 个业务路由。

- 路由层（`src/routes/*`）仅负责参数校验（Zod schema）、鉴权中间件组合与调用 Service，无业务逻辑。
- 服务层（`src/services/*`）按领域拆分：AggregationService（科目树自底向上汇总+公式引擎 DAG 求值）、DataService（CRUD+宽表转长表）、ImportService（Excel 解析+unpivot）、AIProxyService（DeepSeek 代理+脱敏）、IndicatorsService（同比/环比/达成率）、EnterpriseInfoService、FormulaRuleService、ReportService、SubjectAnalysisService、TransactionService、AdminService、DashboardService 等。
- 中间件层（`src/middleware/*`）提供横切能力：authenticate（JWT 校验+用户注入）、requirePermission（Resource:Action 矩阵授权）、scope（公司级数据范围过滤）、soft-delete（全局 status='active' 过滤）、rate-limit、audit、trace-id 等。
- 基础设施（`src/lib/*`）封装 Prisma 单例扩展（软删除+scope 派生客户端）、JWT、密码哈希、日志、响应包装、公式计算、Excel 处理等。

依赖方向严格单向：routes → services → lib/prisma → database；中间件不依赖业务服务，仅读取 req/res 上下文。Prisma 客户端通过 `applySoftDelete` 全局注入软删除过滤，scope 过滤则通过 `prismaForUser(scope)` 按需派生。
