- API 调用统一通过 `lib/api.ts` 的 `ApiClient` 类暴露方法，所有接口以 RESTful 风格组织并按业务域分组（auth/dashboard/indicators/data/admin/ai/reports）。
- 权限控制采用 `RequirePermission` 高阶组件包裹路由或区块，传入 `resource`（模块或模块:子页面编码）和 `action`（如 view/export）两个参数进行判断。
- 认证状态通过 Zustand store（`authStore.ts`）管理，并使用 `zustand/middleware` 的 `persist` 将 user、tokens、isAuthenticated 持久化到名为 `auth-storage` 的 localStorage 键。
- Axios 拦截器统一处理请求头注入 Bearer Token、401 时自动 refreshToken 重试、以及后端统一响应体 `{code, message, data}` 的错误提取。
- 页面级路由在 `App.tsx` 中集中声明，每个业务页面通过 `RequirePermission` 包裹并传入对应的 resource-action 权限标识。
- 组件目录按职责划分：`components/ui` 存放无业务逻辑的原子 UI 组件，`components/<domain>` 存放业务复合组件，每个功能域独立文件夹内聚相关组件。
