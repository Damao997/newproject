模块采用典型的前端分层结构：`src/pages` 按业务域划分页面（dashboard、indicators、data、admin、reports、transactions、inventory、login），通过 `src/App.tsx` 中的 react-router-dom 路由集中注册；所有受保护路由由 `RequirePermission` 组件包裹，实现资源-操作二维权限门禁。状态管理使用 Zustand（`stores/authStore.ts`）并通过 `persist` 中间件持久化到 localStorage；HTTP 请求集中在 `lib/api.ts` 的 `ApiClient` 类中，统一处理 Bearer Token 注入、401 自动刷新、错误消息提取。数据获取通过 `@tanstack/react-query`（`QueryClientProvider` 在 App 根层注入），配合 `hooks/api-queries.ts` 封装查询钩子。UI 组件分为两层：`components/ui` 为基于 Radix UI 的原子组件，`components/*` 为业务复合组件（charts、data-table、dimension、subject-tree、editor、indicators、layout）。样式通过 Tailwind CSS + PostCSS 构建，开发期由 Vite 代理 `/api/v1` 到后端 3001 端口。
