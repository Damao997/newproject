## 简介
本文件面向"库存管理页面"的完整业务流程与实现说明，覆盖库存录入、变更跟踪、盘点管理、预警通知等核心能力；深入讲解库存表格的高级操作（批量导入导出、数据验证、冲突检测）；解释库存状态管理机制（实时库存更新、历史变更记录、版本控制）；提供预警系统配置方法（阈值设置、通知规则、自动处理）；并给出标准化操作流程与最佳实践（入库出库规范、盘点流程、异常处理）。

**重大更新** 本次更新重点介绍了新增的公司份额分布饼图组件，该组件专门用于展示汇总主体下各成员单体公司的库存金额占比情况。通过ECharts环形饼图实现交互式数据可视化，支持点击扇区进行钻取分析。同时增强了主库存页面的过滤和可视化能力，实现了公司选择、期间筛选和用户偏好的持久化存储，显著提升了用户体验和数据洞察能力。

## 核心组件
- 库存页面容器：负责聚合业务逻辑、编排表格、导入导出、盘点与预警联动，以及可视化组件的数据协调。
- 品类分布饼图：展示不同品类库存占比，支持点击筛选和交互操作。
- 品类排名卡片：显示库存数量排名前几的品类，支持排序和筛选。
- **新增** 公司份额饼图：展示汇总主体下各成员单体公司的库存金额占比，支持交互式分析和钻取。
- 库存趋势图表：展示库存数量随时间的变化趋势，支持多时间维度切换。
- 高级数据表格：提供列定义、筛选、排序、批量操作、行内编辑、冲突提示等能力。
- 分页组件：承载服务端分页或客户端分页的数据加载与页码切换。
- 导出工具：将当前视图数据导出为常用格式（如 CSV/Excel）。
- 文件校验：对导入模板进行结构与字段校验，返回错误清单。
- API 封装：统一请求、重试、错误码映射与缓存策略。
- 类型定义：约束库存实体、变更记录、预警规则等数据结构。
- 模拟数据：在本地开发时提供样例库存与变更记录。
- **新增** 页面状态存储：使用Zustand持久化存储管理用户筛选条件和视图状态。
- **新增** 期间状态存储：全局财年选择状态的持久化管理。
- **新增** 公司显示存储：公司简称显示开关的全局状态管理。

**重大更新** 新增了公司份额分布饼图组件和用户偏好持久化机制，分别用于汇总主体的成员公司库存占比分析和跨会话的用户状态保持功能，为用户提供更全面的数据洞察能力和更好的用户体验。

## 架构总览
库存管理页面采用"页面容器 + 可视化组件 + 高级表格 + 工具库 + 状态存储"的分层组织方式。页面容器协调数据获取、用户交互与副作用；可视化组件提供直观的数据分析展示；高级表格聚焦数据操作与管理；工具库提供通用能力（导出、校验、API）；状态存储模块负责用户偏好的持久化管理。

## 详细组件分析

### 库存页面容器（pages/inventory/index.tsx）
职责
- 初始化库存数据与变更记录，维护筛选、分页、批量选择状态。
- 编排可视化组件、导入导出、盘点任务、预警规则配置与联动。
- 调用 API 完成增删改查与批量操作，处理冲突与错误提示。
- **新增** 管理用户偏好状态，通过pageStateStore实现持久化存储。
- **新增** 条件渲染公司份额饼图，仅在选中单个汇总主体时显示。

关键流程
- 数据加载：根据筛选条件与分页参数发起查询，合并变更记录用于展示。
- 可视化渲染：将库存数据传递给饼图、排名、公司份额和趋势组件进行展示。
- 批量操作：收集选中行，执行批量导入/导出/变更提交。
- 导入校验：使用文件校验器对模板进行结构/字段校验，反馈错误清单。
- 导出：基于当前视图数据生成可下载文件。
- 盘点：创建盘点任务，支持差异对比与确认。
- 预警：读取阈值与规则，计算低库存/超储等告警并展示。
- **新增** 状态持久化：用户选择的公司和期间自动保存到localStorage，下次访问时自动恢复。
- **新增** 智能布局：根据筛选条件动态调整图表布局，优化显示效果。

**重大更新** 页面容器现在集成了用户偏好持久化机制和公司份额分析功能，通过Zustand store管理公司选择和期间过滤状态，确保用户设置在不同会话间保持一致。新增的条件渲染逻辑确保公司份额饼图仅在合适的条件下显示。

## 性能考虑
- 分页与懒加载：优先服务端分页，避免一次性加载大量数据。
- 增量更新：变更记录以追加方式渲染，减少整表重绘。
- 可视化组件优化：使用虚拟滚动和按需渲染，避免大数据集的性能问题。
- 图表缓存：对静态图表数据进行缓存，减少重复计算。
- 导出优化：仅导出当前视图数据，必要时异步生成大文件。
- 冲突检测：仅在提交时进行后端一致性校验，前端做轻量预检。
- 缓存策略：对静态配置（如预警规则）进行短期缓存，降低重复请求。
- **新增** 状态存储优化：Zustand store使用浅比较，避免不必要的重渲染。
- **新增** localStorage读写优化：批量更新状态，减少持久化操作频率。
- **新增** 数据去重：避免重复的API请求，利用React Query的缓存机制。
- **新增** 条件渲染优化：公司份额饼图仅在合适条件下渲染，减少不必要的计算。

**重大更新** 新增了用户偏好持久化机制和公司份额分析的性能优化考虑，包括Zustand store的浅比较优化、localStorage的批量写入优化，以及React Query的缓存机制利用，确保在保持用户体验的同时不影响页面性能。

## 故障排查指南
常见问题与定位步骤
- 导入失败：检查文件校验错误清单，确认模板字段与数据类型；查看文件校验器的错误返回。
- 导出为空：确认当前筛选与分页范围是否正确；检查导出工具是否接收到有效数据。
- 批量提交冲突：查看冲突提示行与差异信息；回滚到上一版本后重试。
- 预警未触发：核对阈值与规则配置；检查预警规则更新后的生效时间。
- 历史记录缺失：确认变更记录接口是否返回最新条目；检查分页与过滤条件。
- 可视化组件不显示：检查数据格式是否正确；确认组件依赖的样式和脚本是否正常加载。
- 图表交互异常：检查事件绑定是否正确；确认用户权限是否允许交互操作。
- **新增** 状态恢复失败：检查localStorage是否被禁用或存储空间不足；清除浏览器缓存后重试。
- **新增** 筛选条件丢失：确认Zustand store是否正确初始化；检查持久化存储的版本兼容性。
- **新增** 财年选择不生效：检查periodStore是否正确订阅；确认期间过滤函数的逻辑正确性。
- **新增** 公司份额饼图不显示：检查筛选条件是否为单个汇总主体；确认库存数据是否存在。
- **新增** 公司数据显示异常：检查公司显示存储服务是否正确配置；确认简称显示开关状态。

**重大更新** 新增了用户偏好持久化机制和公司份额分析相关的故障排查指南，帮助用户快速定位和解决状态存储、恢复和相关可视化组件的问题。

- 排名卡片：可配置显示数量、排序方式和对比维度。
- 趋势图表：支持时间粒度切换、图表类型选择和预测参数调整。
- **新增** 公司份额饼图：支持条件渲染、负值处理和中心总额显示。

### 用户偏好持久化配置
- **状态存储配置**：Zustand store使用localStorage进行数据持久化，支持版本控制和智能合并。
- **筛选条件持久化**：公司多选、期间筛选、展开状态等用户操作自动保存。
- **失效处理机制**：自动检测无效的公司编码或期间，进行安全回退。
- **跨会话一致性**：页面刷新和路由切换后，用户偏好自动恢复。
- **新增** 公司显示偏好：公司简称显示开关状态持久化，影响所有相关组件。

### 标准化操作流程与最佳实践
- 入库出库规范：明确单据编号、批次号、单位换算与审批流。
- 盘点操作流程：创建盘点任务 → 差异对比 → 确认调整 → 生成报告。
- 异常处理机制：冲突回滚、错误清单展示、重试与人工介入流程。
- 数据分析流程：定期查看可视化报表 → 识别异常趋势 → 制定改进措施 → 跟踪效果。
- **新增** 用户偏好管理：合理设置筛选条件，利用持久化功能提升工作效率。
- **新增** 公司维度分析：选择合适的汇总主体进行分析，关注成员公司库存分布。

**重大更新** 新增了公司份额分析和用户偏好持久化的配置指南和最佳实践，帮助用户更好地利用新增的功能，提升日常工作的效率和便利性。
