## 简介
本文件为FY200项目的端到端（E2E）测试指南，面向“Excel进、看板/报表出”的财年经营数据分析平台。文档覆盖：
- E2E框架选型与配置（Playwright/Cypress）
- 关键用户流程测试（登录、数据导入、报表生成）
- 跨页面交互（路由跳转、状态保持、权限校验）
- 测试环境搭建与数据准备
- 高级能力（浏览器自动化、截图对比、性能监控）
- AI功能交互流程测试（SSE流式响应）

## 项目结构
FY200采用前后端分离架构：
- 后端：Express + Prisma + PostgreSQL，提供认证、数据导入、指标聚合、报表导出、AI代理等API
- 前端：React/Vite应用，包含登录、仪表盘、数据管理、报表编辑等页面
- 测试：服务端集成测试使用Vitest；E2E建议采用Playwright或Cypress

## 详细组件分析

### 认证与授权（登录、鉴权、权限）
- 登录流程
  - 前端提交用户名/密码，后端校验并签发JWT；前端保存令牌并在后续请求中附加
  - 刷新令牌用于续期访问令牌，支持黑名单登出
- 权限与作用域
  - 权限中间件默认拒绝，需在路由或控制器中声明所需权限
  - 作用域通过Prisma扩展限制数据可见性（如公司维度）

```mermaid
flowchart TD
Start(["开始"]) --> Login["提交登录表单"]
Login --> Validate["校验凭据"]
Validate --> Valid{"凭据有效?"}
Valid --> |否| Error["返回错误"]
Valid --> |是| IssueToken["签发JWT"]
IssueToken --> StoreToken["前端存储令牌"]
StoreToken --> NextReq["后续请求携带Authorization"]
NextReq --> CheckPerm["权限中间件校验"]
CheckPerm --> Allowed{"允许?"}
Allowed --> |否| Deny["拒绝访问"]
Allowed --> |是| ApplyScope["应用作用域"]
ApplyScope --> Success["返回受保护资源"]
```

### 数据导入（Excel上传与校验）
- 导入流程
  - 前端选择Excel文件，后端解析并校验列名、数据类型、必填项
  - 支持批量写入与事务回滚，错误行记录并返回明细
- 关键点
  - 白名单字段映射、单位统一（万元）
  - 并发控制与限流，避免大文件阻塞

```mermaid
flowchart TD
Start(["开始"]) --> Upload["选择Excel文件"]
Upload --> Parse["后端解析Excel"]
Parse --> Validate["校验结构与数据"]
Validate --> Valid{"全部有效?"}
Valid --> |否| ReportErrors["返回错误明细"]
Valid --> |是| WriteDB["批量写入数据库"]
WriteDB --> Commit{"事务成功?"}
Commit --> |否| Rollback["回滚并报错"]
Commit --> |是| Done["返回导入结果"]
```

- 交互流程
  - 前端发起SSE连接，后端按管道处理（polish/analyze），逐步推送片段

- 关键点
  - 脱敏规则确保敏感信息不泄露
  - 超时与错误恢复策略
